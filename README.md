# Україна і світ

Навчальний проєкт з основ HTML/CSS/JS. Веб-сторінка про те, як українська культура й традиції здобувають визнання у світі.

## Зміст

Сторінка складається з трьох тематичних блоків:

- Вишиванка як світовий тренд (про українську вишивку на світовій fashion-арені)
- Петриківський розпис став надбанням ЮНЕСКО (з вбудованим відео на YouTube)
- Українська кулінарія (про котлету по-київськи, борщ і те, як вони з'явилися в Непалі)

## Технології

- HTML5
- CSS3 (без фреймворків)
- JavaScript (ваніль)

## Структура

```
├── index.html    розмітка
├── style.css     стилі
├── script.js     логіка
└── README.md
```

## Як запустити?

Просте відкриття `index.html` у браузері, або через розширення Live Server у VSC.
